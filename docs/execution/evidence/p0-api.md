## Decisión provisional y bloqueos reales

**Single-player es candidato viable sin fork**, como inferencia del catálogo/código, no resultado de integración: los mods corren en ventana y servidor integrado (D:2134–2137; AGENTS.md, “Single player runs on a server thread”). Se puede conservar economía y progresión en servidor y enviar HUD/impulsos al cliente. No existe evidencia estática suficiente para declarar todo el diseño compatible ni para exigir ahora un fork.

Dos riesgos esenciales quedan abiertos: (1) impulso cliente sin una API revisada de impulso server para jugadores y colisión/anticheat sin ensayo; (2) exactitud tras corte al consumir vial/recompensar, sin garantía documentada de commit durable conjunto inventario+attachment. La existencia de un helper all-or-none en memoria no resuelve el segundo. También faltan catálogo/implementación y ensayo de varios hooks con `@API:...@`; no fijar contratos del adaptador sobre ellos todavía.

**Siguiente prueba concreta:** bundle mínimo fijado a `fdc87aecdbd116bf1e08adcd062fcbaea8c2e2ca` en perfil/mundo desechable: `player_logged_in` responde saludo y `player_tick` cuenta ticks (ambos v1 en catálogo instalado), confirmar carga real y que servidor/cliente no se confunden. Después añadir `key` + `mod_key` + gate de foco y un mensaje validado server→cliente que llame push_player, frente a suelo/pared/techo con impulso pequeño y límite total de velocidad propio; guardar/cerrar/reabrir un attachment y un vial consumido. Congelar logs por revisión, no mezclar pruebas de main e instalada.

**Bloqueo actual de C0:** todavía no hay compilación/carga ni prueba física/persistencia acreditada por este encargo. La instalación local difiere del código extensamente revisado; el probe debe construir su API contra la revisión instalada. El principal informa toolchain aislada instalada, pero este informe no verifica esa instalación. No falta por evidencia una API genérica de “mod Rust”; falta demostrar el ciclo mínimo y resolver semántica de movimiento/transacción. P1 no debe presentar compatibilidad ni cooperativo como verificados.
